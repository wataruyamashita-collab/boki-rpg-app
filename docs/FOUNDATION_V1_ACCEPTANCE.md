## 代表問題による拡張性

必要に応じて現在の公式出題範囲を確認し、対象能力・条件・答案・解説・別計算を固定する。
各代表例は表示→回答→採点→解説→保存→復習の必要部分を検証する。canonical300へ未承認IDを足さず、隔離fixture/試作で検証できる。

| 代表問題 | 選定/実行 | Type・根拠・実行証跡 |
|---|---|---|
| 3級仕訳 | 既存3級の証拠あり。共通の拡張検証表としては未確定 | 未判定 |
| 2級商業簿記の代表的複合問題 | 未実行 | 未判定 |
| 2級工業簿記・原価計算の代表的計算表 | 未実行 | 未判定 |
| 1級を見据えた代表的複合計算 | 未実行 | 未判定 |
| 会計学の概念問題 | 未実行 | 未判定 |

**Type A**: データ追加だけで対応。**Type B**: 独立コンポーネント追加で対応。**Type C**: 共通Core変更が必要。
Type Bは失敗ではない。Type Cは必要変更と既存への影響を明示し再検証する。
採点だけで表示/保存/復習も対応済みとしない。代表例から1級全範囲対応済み、未来の全形式を無改修で処理可能と一般化しない。
